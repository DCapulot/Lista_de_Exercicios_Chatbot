# 🤖 Lista de Exercícios — Chatbot em Python

Exercícios que fiz para aprender Python, organizados por aula, com foco na construção de um chatbot.


## 🛠️ Tecnologias

- Python 3
- Git e GitHub

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/DCapulot/Lista_de_Exercicios_Chatbot.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Lista_de_Exercicios_Chatbot
   ```

3. Execute um dos arquivos (troque `nome_do_arquivo.py` pelo nome real; as pastas têm espaço no nome, então use aspas):

   ```bash
   python "Aula 1/nome_do_arquivo.py"
   ```

> Dependendo do sistema, use `python3` no lugar de `python`.

## 🎯 Objetivo

Praticar lógica de programação e fundamentos de Python, evoluindo aula a aula até um chatbot funcional. Novos exercícios serão adicionados conforme o curso avança.
